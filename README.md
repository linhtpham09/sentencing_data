# Summary of Repository 

This repository serves as the documentation of research between Charlotte Lawrence and Linh Pham for Fiona Doherty (YLS). This repository stores the scripts for pulling data from the team's Google Cloud Platform (GCP) BigQuery Service which stores USSC data. 

The primary focus of this project was to replicate the methodology for USSC's [2017](https://www.ussc.gov/research/research-reports/2017-demographic-differences-federal-sentencing)  and [2023] (https://www.ussc.gov/research/research-reports/2023-demographic-differences-federal-sentencing) reports on demogrpahic differences in federal sentencing. By replicating the original methodology, we aimed to apply the methodology in the respective of other racial-gender groups.
