# Archive

Historical drafts and side analyses, kept for reference. The current,
canonical pipeline and reports live in `final_scripts_2017model/` and
`final_scripts_2023model/` at the repository root.

- **`early_drafts/`** — Early, superseded versions of the preprocessing and
  analysis scripts, from before the pipeline was split into the 2017/2023
  model folders.
- **`reports_history/`** — Earlier memos and their source R Markdown, one
  representative version kept per memo (intermediate duplicate drafts of the
  same memo were removed).
- **`region_breakdown/`** — Exploratory regional breakdown analysis.
- **`ryan_cotter_regression_tables/`** — Regression tables and scripts
  prepared for an external collaborator (Ryan Cotter) using an earlier
  snapshot of the data.
